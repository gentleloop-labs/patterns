# Concepts

## Selected: OCD, out loud

- Strategy: relatable internal dialogue
- Hook: one concise description of the loop
- Visual: Maya speaking with Loop inside a thought cloud
- Product turn: one real or source-faithful Patterns screen
- Motion: expression and text crossfades only
- Reason: directly fits the requested low-complexity render pipeline and remains clear without voiceover

## Shelved: moving metaphor

Animated locks, browser tabs, ladders, rewinds, and waves were rejected because they add production complexity without improving the core conversation.

## Shelved: screen-first tutorial

A UI tutorial would explain features but would be less recognizable and emotionally specific as a reel opener.
