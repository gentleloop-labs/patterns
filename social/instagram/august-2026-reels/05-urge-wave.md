# Reel 05: An urge is a wave, not a deadline

## Purpose

Explain urge surfing through a simple static wave metaphor while preserving the core point: observation is not a technique for forcing the urge away.

## Specs

- Date: Aug 31
- Duration: 23 seconds
- Background: static wave curve labeled rise, crest, and shift
- Product ending: code-native Urge Surfing poster for Patterns Pro
- Hook text: `THE URGE SAYS NOW`

## Fixed composition

- Maya remains waist-up in the lower-left.
- Loop remains inside the thought cloud in the upper-right.
- A static wave curve remains behind them.
- Labels on the curve may change emphasis, but the wave itself does not animate.

## Final dialogue

**Loop:** This urge is urgent. Act now.

**Maya:** Or I can watch it change.

**Loop:** What if it gets stronger?

**Maya:** Then I notice the rise, the crest, and the shift.

**Loop:** You're not making it disappear?

**Maya:** No. I'm practicing not obeying it.

**Maya:** Patterns can guide the timer and reflection. Urge Surfing is a Pro tool.
