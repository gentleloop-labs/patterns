# Patterns OCD education posts

Five original 1080 × 1350 px Instagram posts inspired by the approachable, illustrated education style in the supplied reference.

## Posts

1. Why reassurance never feels finished
2. Mental compulsions can be invisible
3. ERP has two parts—and both matter
4. Urgency is part of the alarm
5. Recovery is not always feeling calm

Each post is designed to work as a standalone feed post. The set uses Patterns' existing Fraunces/Manrope typography and logo with original generated illustrations.

## Regenerate

From this folder:

```sh
node render.js
```

Final PNGs are written to `output/`. Captions and clinical sources are included alongside the renderer.
